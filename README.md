# EDGE-TO-CLOUD-HEAT-MONITORING-FOR-INDUSTRIAL-ENVIRONMENTS
Edge-to-Cloud Heat Monitoring for Industrial Environments is an IoT-based system using LPC2148, LM35, MQ-2, and ESP01 to monitor temperature and gas levels. It sends real-time data to the Thing Speak cloud, activates a buzzer during gas detection, and enables remote monitoring for improved industrial safety and efficiency.
